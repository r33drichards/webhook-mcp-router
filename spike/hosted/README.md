# Synthetic official SDK CGI fixture

This is a focused compatibility fixture, separate from the uncompiled combined webhook/OPA fork. `main.go` uses the official pinned MCP SDK with `Stateless` and `JSONResponse`, hosted through Go `cgi.Serve`. It implements four synthetic tools used by `ci/hosted-e2e.py`: create/list/delete a registration and emit a nonce to one fixed operator-configured HTTPS callback. It does not accept caller-supplied destination URLs.

`/mcp` requires a bearer test token and rejects browser Origin requests; `/receipts` uses a distinct read token. `/callback` verifies the raw-body Standard Webhooks HMAC and timestamp before JSON parsing, then records a write-once receipt. Envelope/signing names follow the inspected WeeChat source. This is **not full events extension compatibility**: discovery capabilities, events/subscribe verification challenge, TTL/cursor semantics and unsubscribe remain unfinished. No approximate custom protocol is presented as SDK success.

Configuration requires `POC_STATE_DIR`, `POC_RECEIPT_DIR` (distinct absolute paths), `POC_TEST_TOKEN`, `POC_RECEIPT_TOKEN` (at least 32 characters), `POC_CALLBACK_URL` (fixed reviewed HTTPS URL), and `POC_WEBHOOK_SECRET` (`whsec_` plus base64 24–64 byte key). No real credentials are supplied. Callback target is trusted operator configuration; there is no arbitrary-user URL registration. Proxy discovery and redirects are disabled. Runtime DNS/TLS/outbound behavior still needs validation.

Registrations use filesystem marker files and receipts are separate write-once JSON files. This supports a minimal single-host fixture, not the selected production shared database or enforced RO/RW DB roles. Mapped local persistence does not establish Edge volume semantics. No automatic retry/outbox is implemented. A partial receipt write fails verification; replay receives 409. Test-only files require lifecycle cleanup; do not enable unbounded public access.

Validated locally: `go test core.go core_test.go` passes using stdlib only, including native loopback TLS delivery. The official SDK `go test -mod=mod ./...` fails during dependency setup with `GOPROXY=off` because segmentio/encoding is absent. No SDK or WASI compatibility pass is claimed. CI now attempts full native SDK tests, WASI build, and `ci/sdk-cgi-check.py` fresh-instance Wasmer assertions. Hosted E2E remains separately gated. Nix build and deployment manifests are still pending.
